# Mobile Toolkit (releases)

Tools for using Obsidian on a tablet or phone, especially with a stylus. It includes:

- explicit pen Write and Scroll modes;
- shields for the screen-edge gestures that interrupt writing;
- a floating control rail and punctuation strip;
- text size controls;
- a touch-friendly canvas for finger and pen;
- larger Chinese text in chosen notes;
- a banner that warns when Obsidian Sync stops working.

This repo holds the release builds. The source is developed in a separate private repo, so issues here may not get a reply.

## Install with BRAT

1. In Obsidian, install and enable **BRAT** from Community plugins.
2. In BRAT's settings, choose **Add beta plugin**.
3. Enter `masonroyal/mobile-toolkit-releases` and pick the latest version.
4. Enable **Mobile Toolkit** under Community plugins.

No GitHub token is needed. BRAT can keep the plugin up to date from here.

## Install by hand

Download `main.js`, `manifest.json` and `styles.css` from the latest release into `<your vault>/.obsidian/plugins/mobile-toolkit/`, then enable the plugin.

This is beta software. Back up your vault before trying it.
